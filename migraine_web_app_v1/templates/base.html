Add your dataset

No dataset has been trained yet. Add the dataset from your reference and the app builds its form, models and charts from it.

  1. Save your reference dataset as a CSV file in the data folder of the project. Any file name works.
  2. Make sure it has a Type column with the known answer. Every other column is used as an input: 0/1 or Yes/No columns become symptom buttons, number columns become sliders.
  3. Run python train.py, then restart python app.py and reload this page.

Two types of dataset

Category dataset Type holds the migraine category, e.g. “Typical aura with migraine”, “Migraine without aura”. Trains step 2, and step 1 is built from it. Example: the Kaggle Migraine Symptom Classification dataset
Migraine or not dataset (optional) Type is Migraine / No migraine. If present, it trains step 1 instead.
